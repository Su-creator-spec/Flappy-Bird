 # Flappy Bird 

A simple recreation of the classic **Flappy Bird** game.  
Built for learning, experimenting, and having fun with game development concepts.

---

##  Features
- Classic **Flappy Bird gameplay**: tap/press to keep the bird flying.
- **Obstacle pipes** with increasing difficulty.
- **Score tracking** to challenge yourself and friends.
- Lightweight and easy to run locally.

##  Getting Started

### Prerequisites
- Install [Python 3.x](https://www.python.org/downloads/)  
- Install [Pygame](https://www.pygame.org/wiki/GettingStarted) library:
  ```bash
  pip install pygame
  ```
### Running the Game
1. Clone the repository:
  ```bash
  git clone https://github.com/Su-creator-spec/Flappy-Bird.git
```
2.Navigate into the project folder:
```bash
cd Flappy-Bird
```
3.Run the game:
```bash
python main.py
```
